PAGINA DE ESCANDALO — COMO USARLA
==================================

Abrir en la compu: node scripts/servir.js y entrar a http://localhost:8080
(las páginas usan URLs limpias: /galeria, /calendario, /historia; no funcionan con doble clic en el .html)

DONDE SUBIR LAS FOTOS (carpeta assets/)
---------------------------------------
assets/logos/logo.png        -> logo chico (bomba) para menu y footer
assets/logos/logo-full.png   -> logo completo con texto, portada
assets/logos/_originales/    -> archivos originales del zip
assets/hero/hero.jpg         -> foto grande de portada (horizontal, idealmente 1920px de ancho)
assets/jugadores/            -> una foto por jugador (vertical, tipo 3:4). Nombre = el que pusiste en js/data.js
assets/torneo/             -> fotos y videos de la galería (se listan en js/data.js, GALERIA)

EDITAR TEXTOS, JUGADORES, PARTIDOS Y RESULTADOS
-----------------------------------------------
Todo esta en js/data.js. Cambia los nombres, fechas, numero de WhatsApp, mail, etc.
Si una foto no existe, la pagina muestra un reemplazo automaticamente (no se rompe).

COLORES
-------
Estan al principio de css/style.css (--a rosa, --b lima). Se pueden cambiar por los colores del logo.

AGREGAR UN JUGADOR
------------------
1. Su carta en assets/jugadores/<nombre-apellido>.webp (720x1280)
2. La misma carta en JPG en assets/jugadores/compartir/<nombre-apellido>.jpg (para compartir/descargar)
3. Sus datos en JUGADORES, en js/data.js
4. node scripts/jugadores.js  (genera su link para compartir: /jugador/<nombre-apellido>)

BASE DE DATOS LOCAL (Supabase)
------------------------------
Requiere Docker Desktop abierto.
  npx supabase start       -> levanta la base (la 1ª vez descarga imágenes)
  npx supabase stop        -> la apaga
  npx supabase db reset    -> la borra y la recrea con la estructura y los datos de prueba
  node scripts/generar-seed.js -> regenera supabase/seed.sql desde js/data.js
Panel visual (Studio): http://127.0.0.1:54323     API: http://127.0.0.1:54321
Consultas SQL: Studio -> SQL Editor, o:  docker exec -it supabase_db_escandalo psql -U postgres

QUE DATOS USA EL SITIO
----------------------
En localhost: lee jugadores, torneos y partidos de la base local (si está prendida).
Si la base no responde: usa la última copia guardada en el navegador, y si no hay, js/data.js.
En escandaloultimate.com: usa js/data.js (todavía no hay base real). Se configura en js/config.js.
Los textos de Nosotros, los hitos y la galería siguen en js/data.js.

LOGIN (solo en local por ahora)
-------------------------------
Página: /login  (http://localhost:8080/login). Se elige el jugador y se entra con la contraseña sunombre123 (la misma para todos).
Los usuarios viven en la base local (Supabase Auth). Crearlos o resetearlos:  node scripts/crear-usuarios.js
(después de `npx supabase db reset` hay que volver a correrlo). Si el ingreso es correcto, va al inicio.
Contraseñas: todos usan sunombre123, salvo quien tenga una clave propia en supabase/claves-locales.json
(archivo que NO se sube a Git, formato {"slug": "clave"}). Después de editarlo: node scripts/crear-usuarios.js
La contraseña la valida la base de datos; distingue mayúsculas de minúsculas.
